Launchers ​

This page lists the current known working launchers that can be used to launch the Administrator.

Ballista ​

https://github.com/kayyagari/ballista

Ballista is a launcher by Kiran Ayyagari, built with the Tauri framework and licensed under MPL-2.0. Releases ship for macOS, Windows and Linux.

Launcher ​

https://github.com/diridium-com/launcher

Launcher is a fork of Ballista, also built on Tauri and licensed under MPL-2.0. It includes a Java console output viewer, server TLS certificate verification with trust management, and real-time server connectivity status, and it can import existing connections from MCAL's data/connections.json. Installers are published for macOS, Windows and Linux.

JNLP Launcher Project ​

https://github.com/igearfs/jnlp-launcher-project

JNLP Launcher Project is written fully in Java. Releases ship for Windows and for Debian and Ubuntu on amd64. There is no macOS build.

Mirth Connect Administrator Launcher ​

MCAL is the original launcher. Although closed source, it still works with the current versions of Open Integration Engine.
