Database ​

PropertyDefaultDescription
databasederbyDatabase type: derby, mysql, postgres, oracle, sqlserver
database.url(Derby embedded)JDBC connection URL
database.driver(none)JDBC driver class override (e.g. com.microsoft.sqlserver.jdbc.SQLServerDriver)
database.username(empty)Database username
database.password(empty)Database password
database.max-connections20Read/write connection pool size
database-readonly.max-connections20Read-only connection pool size. When the key is absent, the server writes database-readonly.max-connections = 20 into the file at first start
database.enable-read-write-splittrueEnable separate read-only pool. When the key is absent, the split is on and the server writes database.enable-read-write-split = true into the file at first start
database.poolHikariCPConnection pool type: HikariCP or DBCP
database.write-pool-cachefalseUse the read/write pool for internal caches instead of the read-only pool
database.connection.maxretry2Startup connection retry attempts
database.connection.retrywaitinmilliseconds10000Wait between retries (ms)

Password policy ​

PropertyDefaultDescription
password.minlength15Minimum password length
password.minupper0Minimum uppercase characters
password.minlower0Minimum lowercase characters
password.minnumeric0Minimum numeric characters
password.minspecial0Minimum special characters
password.retrylimit100Failed attempts before lockout (0 = no lockout)
password.lockoutperiod1Lockout duration in hours (0 = no lockout, even when password.retrylimit is set)
password.expiration0Days until expiration (0 = never)
password.graceperiod0Days a user may still log in after the password expires (0 = unlimited, -1 = no grace period)
password.reuseperiod0Days before a previous password may be reused (0 = always allow, -1 = never)
password.reuselimit0Times a previous password may be reused (0 = no limit, -1 = never)

These are the values conf/mirth.properties ships with. A password.* key that is absent from the file is read as 0, so deleting password.minlength, password.retrylimit or password.lockoutperiod turns that rule off.
